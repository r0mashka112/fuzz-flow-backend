# Fuzz Flow — Backend

Backend-сервис для системы распределённого фаззинга. Связывает агрегатор и дашборд: принимает данные от агрегатора, сохраняет в базу и предоставляет API для фронта.

## Зона ответственности

Backend не управляет Docker-контейнерами, не запускает фаззер и не валидирует результаты. Задачи:

- приём данных от агрегатора через REST API
- сохранение результатов в PostgreSQL
- предоставление данных для дашборда

## Модель данных

Project 1 → * Commit 1 → * FuzzingSession 1 → * FuzzWorker
                                    1 → * Crash

- Project — проект для фаззинга
- Commit — коммит (один коммит может иметь несколько сессий)
- FuzzingSession — сессия фаззинга (статус, метрики, время)
- FuzzWorker — воркер внутри сессии (покрытие, обработанные входные данные)
- Crash — найденная ошибка (тип, входные данные, вывод санитайзера)

## Поток данных

Агрегатор → Backend API → PostgreSQL → Frontend

1. Агрегатор отправляет данные в API (сессии, воркеры, ошибки)
2. Backend сохраняет в базу
3. Фронт запрашивает данные через API для отображения дашборда

## Технологии

- Python 3.12+
- FastAPI (асинхронный режим)
- SQLAlchemy 2.0 + asyncpg
- PostgreSQL 16
- Pydantic v2
- Poetry
- Alembic

## Установка

- poetry install
- poetry run alembic upgrade head
- python3 -m app.main
